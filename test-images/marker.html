HiLo Card AR

Instruções:

  1. Imprima este cartão em papel branco
  2. Escaneie o QR Code com seu smartphone para abrir a aplicação AR
  3. Permita o acesso à câmera quando solicitado
  4. Aponte a câmera para o padrão quadrado acima
  5. O modelo 3D aparecerá sobre o padrão

Dicas para impressão:

  • Use papel branco comum
  • Certifique-se de que a impressão está nítida e com bom contraste
  • Não dobre ou amasse o padrão quadrado
  • Mantenha o cartão em bom estado para melhor reconhecimento
